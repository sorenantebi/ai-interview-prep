# Quant Dev question bank

Short-answer questions in the style of getcracked.io, quantquestions.io and trading-firm C++ interviews, written in our own words.
One file per topic (`NN Topic.md`). Each question:

    ## <Title> · <Easy|Medium|Hard>

    <the question; code in ```cpp blocks>

    ### Answer

    <the short answer first, then why>

The app shows the question, lets you type your answer, then reveals ### Answer. Your "got it / again" marks are saved in quiz.json.
