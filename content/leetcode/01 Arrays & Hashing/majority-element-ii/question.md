# Majority Element II

**Topic:** Arrays & Hashing · **Difficulty:** Medium

## Problem

Given an integer array `nums` of size `n`, return all elements that appear more than `⌊n / 3⌋` times. The answer may be returned in any order.

Follow up: can you solve it in linear time and `O(1)` extra space?

## Examples

**Example 1**
```text
Input: nums = [3,2,3]
Output: [3]
```

**Example 2**
```text
Input: nums = [1]
Output: [1]
```

**Example 3**
```text
Input: nums = [1,2]
Output: [1,2]
```

## Constraints

- `1 <= nums.length <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`
