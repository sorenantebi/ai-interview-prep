# Reverse String

**Topic:** Two Pointers · **Difficulty:** Easy

## Problem

You are given a string as an array of characters `s`. Reverse the array so that its characters appear in the opposite order.

The reversal must be done in-place, by modifying the input array directly, using only O(1) extra memory. The function returns nothing.

## Examples

**Example 1**
```text
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
```

**Example 2**
```text
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]
```

## Constraints

- `1 <= s.length <= 10^5`
- `s[i]` is a printable ASCII character.
