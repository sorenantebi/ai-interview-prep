# Valid Palindrome II

**Topic:** Two Pointers · **Difficulty:** Easy

## Problem

Given a string `s`, return `true` if it can become a palindrome after deleting at most one character from it, and `false` otherwise.

## Examples

**Example 1**
```text
Input: s = "aba"
Output: true
```

**Example 2**
```text
Input: s = "abca"
Output: true
Explanation: You could delete the character 'c'.
```

**Example 3**
```text
Input: s = "abc"
Output: false
```

## Constraints

- `1 <= s.length <= 10^5`
- `s` consists of lowercase English letters.
