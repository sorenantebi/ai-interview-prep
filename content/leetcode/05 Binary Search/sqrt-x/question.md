# Sqrt(x)

**Topic:** Binary Search · **Difficulty:** Easy

## Problem

Given a non-negative integer `x`, return the square root of `x` rounded down to the nearest integer. The returned integer must also be non-negative.

You must not use any built-in exponent function or operator. For example, do not use `pow(x, 0.5)` in C++ or `x ** 0.5` in Python.

## Examples

**Example 1**
```text
Input: x = 4
Output: 2
```
The square root of 4 is 2, so we return 2.

**Example 2**
```text
Input: x = 8
Output: 2
```
The square root of 8 is 2.82842..., and since we round it down to the nearest integer, 2 is returned.

## Constraints

- `0 <= x <= 2^31 - 1`
