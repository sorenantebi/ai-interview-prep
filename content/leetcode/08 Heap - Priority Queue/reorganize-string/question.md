# Reorganize String

**Topic:** Heap - Priority Queue · **Difficulty:** Medium

## Problem

Given a string `s`, rearrange its characters so that no two adjacent characters are the same.

Return any valid rearrangement of `s`, or return an empty string `""` if no such rearrangement exists.

## Examples

**Example 1**
```text
Input: s = "aab"
Output: "aba"
```

**Example 2**
```text
Input: s = "aaab"
Output: ""
```

## Constraints

- `1 <= s.length <= 500`
- `s` consists of lowercase English letters.
