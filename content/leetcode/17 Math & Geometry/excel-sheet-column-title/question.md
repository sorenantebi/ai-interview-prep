# Excel Sheet Column Title

**Topic:** Math & Geometry · **Difficulty:** Easy

## Problem

Given a positive integer `columnNumber`, return the column title that corresponds to it in an Excel sheet.

Column titles follow this pattern:

```text
A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28
...
```

## Examples

**Example 1**
```text
Input: columnNumber = 1
Output: "A"
```

**Example 2**
```text
Input: columnNumber = 28
Output: "AB"
```

**Example 3**
```text
Input: columnNumber = 701
Output: "ZY"
```

## Constraints

- `1 <= columnNumber <= 2^31 - 1`
