# N-Queens II

**Topic:** Backtracking · **Difficulty:** Hard

## Problem

The n-queens puzzle asks you to place `n` queens on an `n x n` chessboard so that no two queens attack each other. Two queens attack each other if they share the same row, column, or diagonal.

Given an integer `n`, return the number of distinct solutions to the n-queens puzzle.

## Examples

**Example 1**
```text
Input: n = 4
Output: 2
```
There are two distinct ways to place 4 queens on a 4 x 4 board without any attacking another.

**Example 2**
```text
Input: n = 1
Output: 1
```

## Constraints

- `1 <= n <= 9`
