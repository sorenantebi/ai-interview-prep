# Add Binary

**Topic:** Bit Manipulation · **Difficulty:** Easy

## Problem

You are given two strings `a` and `b`, each representing a non-negative binary number. Return the sum of the two numbers, also as a binary string.

## Examples

**Example 1**
```text
Input: a = "11", b = "1"
Output: "100"
```

**Example 2**
```text
Input: a = "1010", b = "1011"
Output: "10101"
```

## Constraints

- `1 <= a.length, b.length <= 10^4`
- `a` and `b` consist only of `'0'` or `'1'` characters.
- Each string does not contain leading zeros except for the zero itself.
