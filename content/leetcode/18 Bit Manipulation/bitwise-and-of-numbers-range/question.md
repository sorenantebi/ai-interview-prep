# Bitwise AND of Numbers Range

**Topic:** Bit Manipulation · **Difficulty:** Medium

## Problem

You are given two integers `left` and `right` that define the inclusive range `[left, right]`. Return the bitwise AND of every integer in that range.

## Examples

**Example 1**
```text
Input: left = 5, right = 7
Output: 4
```

**Example 2**
```text
Input: left = 0, right = 0
Output: 0
```

**Example 3**
```text
Input: left = 1, right = 2147483647
Output: 0
```

## Constraints

- `0 <= left <= right <= 2^31 - 1`
