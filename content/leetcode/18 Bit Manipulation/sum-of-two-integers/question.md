# Sum of Two Integers

**Topic:** Bit Manipulation · **Difficulty:** Medium · [LeetCode](https://leetcode.com/problems/sum-of-two-integers/) · [NeetCode](https://neetcode.io/problems/sum-of-two-integers)

## Problem

Given two integers `a` and `b`, return their sum **without using the `+` or `-` operators**.

## Examples

**Example 1**
```text
Input: a = 1, b = 2
Output: 3
```

**Example 2**
```text
Input: a = 2, b = 3
Output: 5
```

**Example 3**
```text
Input: a = -5, b = -7
Output: -12
```

## Constraints

- `-1000 <= a, b <= 1000`
