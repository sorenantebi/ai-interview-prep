# Maximum Subarray

**Topic:** Greedy · **Difficulty:** Medium · [LeetCode](https://leetcode.com/problems/maximum-subarray/) · [NeetCode](https://neetcode.io/problems/maximum-subarray)

## Problem

Given an integer array `nums`, find the contiguous, non-empty subarray with the largest sum and return that sum.

## Examples

**Example 1**
```text
Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: The subarray [4,-1,2,1] sums to 6.
```

**Example 2**
```text
Input: nums = [1]
Output: 1
```

**Example 3**
```text
Input: nums = [5,4,-1,7,8]
Output: 23
```

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
