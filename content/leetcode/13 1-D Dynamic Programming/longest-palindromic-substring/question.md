# Longest Palindromic Substring

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium · [LeetCode](https://leetcode.com/problems/longest-palindromic-substring/) · [NeetCode](https://neetcode.io/problems/longest-palindromic-substring)

## Problem

Given a string `s`, return the longest contiguous substring of `s` that reads the same forwards and backwards. If several substrings share the maximum length, any one of them is accepted.

## Examples

**Example 1**
```text
Input: s = "babad"
Output: "bab"
Explanation: "aba" is also accepted.
```

**Example 2**
```text
Input: s = "cbbd"
Output: "bb"
```

## Constraints

- `1 <= s.length <= 1000`
- `s` consists only of digits and English letters.
