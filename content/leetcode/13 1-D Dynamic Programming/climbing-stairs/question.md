# Climbing Stairs

**Topic:** 1-D Dynamic Programming · **Difficulty:** Easy · [LeetCode](https://leetcode.com/problems/climbing-stairs/) · [NeetCode](https://neetcode.io/problems/climbing-stairs)

## Problem

You are at the bottom of a staircase with `n` steps. Each move you climb either `1` or `2` steps. Return the number of distinct sequences of moves that take you exactly to the top (step `n`).

## Examples

**Example 1**
```text
Input: n = 2
Output: 2
Explanation: 1+1 or 2.
```

**Example 2**
```text
Input: n = 3
Output: 3
Explanation: 1+1+1, 1+2, 2+1.
```

## Constraints

- `1 <= n <= 45`
