# Integer Break

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

## Problem

Given an integer `n`, split it into the sum of `k` positive integers, where `k >= 2`, so that the product of those integers is as large as possible.

Return the maximum product you can obtain.

## Examples

**Example 1**
```text
Input: n = 2
Output: 1
Explanation: 2 = 1 + 1, 1 × 1 = 1.
```

**Example 2**
```text
Input: n = 10
Output: 36
Explanation: 10 = 3 + 3 + 4, 3 × 3 × 4 = 36.
```

## Constraints

- `2 <= n <= 58`
